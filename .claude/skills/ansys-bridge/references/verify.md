# Проверовъчни формули

Смисълът на този файл: **преди всеки скрипт се дава очаквано число.** Без предварително очакване няма как да се хване сгрешено закрепване, сбъркана единица или несходена мрежа — цветната картинка изглежда еднакво убедителна и в двата случая.

Единици навсякъде: mm, N, MPa.

Приемливо разминаване между аналитика и FEA:
- **под 5%** — за прости случаи (греда, опън, тръба). Повече означава грешка някъде.
- **5–15%** — нормално, когато аналитиката е опростена (пренебрегнати закръгления, идеализирано закрепване).
- **над 30%** — не се обяснява с „приблизителност". Търси се грешка, обикновено в закрепването или в единиците.

## 1. Геометрични характеристики на сечения

| Сечение | Площ A | Инерционен момент I | Съпротивителен момент W |
|---|---|---|---|
| Правоъгълник b×h | b·h | b·h³/12 | b·h²/6 |
| Кръг Ø d | πd²/4 | πd⁴/64 | πd³/32 |
| Тръба D/d | π(D²−d²)/4 | π(D⁴−d⁴)/64 | π(D⁴−d⁴)/(32D) |

Огъването става около оста, перпендикулярна на посоката на силата — при правоъгълник `h` е размерът **по посока на силата**. Разменени b и h дават грешка от няколко пъти; това е най-честата глупава грешка в бързи сметки.

## 2. Огъване на греди

| Случай | Макс. момент | σ_max | Провисване |
|---|---|---|---|
| Конзола, сила F на края | F·L | F·L/W | F·L³/(3EI) |
| Конзола, равномерен товар q [N/mm] | q·L²/2 | q·L²/(2W) | q·L⁴/(8EI) |
| Проста греда, F в средата | F·L/4 | F·L/(4W) | F·L³/(48EI) |
| Проста греда, равномерен товар q | q·L²/8 | q·L²/(8W) | 5q·L⁴/(384EI) |
| Защипана в двата края, F в средата | F·L/8 | F·L/(8W) | F·L³/(192EI) |

**Пример за проверка (задача 1 от стълбата):**
Конзола 200×20×10 mm, стомана, сила 500 N надолу в края.
h = 10 (по посока на силата), b = 20.
W = 20·10²/6 = 333 mm³ → σ = 500·200/333 = **300 MPa**
I = 20·10³/12 = 1667 mm⁴ → δ = 500·200³/(3·210000·1667) = **3.8 mm**

Ако Ansys покаже 300 MPa и 3.8 mm — всичко работи. Ако покаже 3.8 MPa, значи е сбъркана единица. Ако покаже 150, значи закрепването пропуска.

## 3. Опън, срязване, усукване

```
Опън:      σ = F / A
Срязване:  τ = F / A            (просто срязване)
Усукване:  τ = T / Wp,          Wp = πd³/16 (плътен вал)
Ъгъл на усукване: φ = T·L/(G·Ip),  G = E/(2(1+ν)) ≈ 81000 MPa за стомана
                  Ip = πd⁴/32
```

## 4. Концентрация на напрежение

В остър преход напрежението скача. Множителят се нарича коефициент на концентрация Kt:

```
σ_макс = Kt · σ_номинално
```

**Пластина с централен кръгъл отвор, опън** (задача 2 от стълбата) — това е класическият тест дали мрежата е достатъчна:

```
σ_ном = F / ((w − d) · t)          (по нетното сечение)

Kt = 3.00 − 3.14·(d/w) + 3.67·(d/w)² − 1.53·(d/w)³
```

При много малък отвор спрямо ширината Kt → 3.0. Това е известно от 1898 г. и е най-добрият тест за начинаещ: ако FEA даде 3, инструментът е настроен правилно.

Пример: пластина 40 mm широка, отвор Ø10, дебелина 5, сила 5000 N.
d/w = 0.25 → Kt = 3.00 − 0.785 + 0.229 − 0.024 = **2.42**
σ_ном = 5000/((40−10)·5) = 33.3 MPa
σ_макс ≈ **80.6 MPa**

**Други типични Kt:** вътрешен ъгъл със закръгление r при дебелина t — Kt ≈ 1.5…2.5 според r/t; изострен ъгъл без закръгление — Kt → ∞ (виж `errors.md` за сингулярностите).

## 5. Собствени честоти

Греда със сечение A [mm²], плътност ρ [t/mm³]:

```
f = (λ² / 2π) · √( E·I / (ρ·A·L⁴) )      [Hz]
```

λ² по вида на закрепването (първа форма):

| Закрепване | λ² |
|---|---|
| Конзола (защипана—свободна) | 3.52 |
| Проста греда (шарнир—шарнир) | 9.87 |
| Защипана в двата края | 22.4 |
| Защипана—шарнир | 15.4 |

**Пример:** същата конзола 200×20×10, стомана.
I = 1667 mm⁴, A = 200 mm², ρ = 7.85e-9
E·I = 210000 · 1667 = 3.5e8
ρ·A·L⁴ = 7.85e-9 · 200 · 200⁴ = 2.512e-3
√(3.5e8 / 2.512e-3) = √1.393e11 = 373 200
f = (3.52/6.283) · 373 200 = **209 Hz**

Единичен товар с маса m на края на конзола:

```
f ≈ (1/2π) · √(k/m),   k = 3EI/L³ [N/mm],  m [t]
```

## 6. Изкълчване

Натисната тънка пръчка се губи не от смачкване, а от изкривяване:

```
P_кр = π²·E·I / (K·L)²
```

| Закрепване | K |
|---|---|
| Шарнир—шарнир | 1.0 |
| Защипана—свободна | 2.0 |
| Защипана—защипана | 0.5 |
| Защипана—шарнир | 0.7 |

Ако P_кр излезе по-малко от натоварването, статичният анализ е безсмислен — детайлът се губи преди да достигне якостта си.

## 7. Контакт по Херц

Сфера R върху равнина, сила F:

```
1/E* = (1−ν₁²)/E₁ + (1−ν₂²)/E₂

Радиус на петното:   a = (3·F·R / (4·E*))^(1/3)
Макс. налягане:      p_max = 3F / (2π·a²)
Сближаване:          δ = a²/R
```

Два цилиндъра с успоредни оси, дължина L, сила F:

```
1/R* = 1/R₁ + 1/R₂
Полуширина:  b = √(4·F·R* / (π·L·E*))
p_max = 2F / (π·b·L)
```

Контактното налягане при Херц е учудващо високо — редовно излиза над границата на провлачване при съвсем скромни сили. Това не е грешка, а естеството на точковия контакт.

## 8. Болтове

```
Сила на затягане от момент:   F = T / (K·d)
```
K ≈ 0.20 сух, 0.15 смазан, 0.12 с покритие. Разсейването е ±25% — това е реалната точност на затягането с ключ.

```
Напрежение в болта:  σ = F / A_s
```

Напрегнати сечения A_s [mm²]: M6 — 20.1; M8 — 36.6; M10 — 58.0; M12 — 84.3; M16 — 157; M20 — 245; M24 — 353.

Препоръчана сила на затягане ≈ 70% от границата на провлачване по A_s. За M12 клас 8.8 (Rp0.2 = 640 MPa): F ≈ 0.7·640·84.3 ≈ **37.8 kN**, което при K=0.2 дава момент T ≈ 37800·0.2·12 ≈ **91 Nm**.

## 9. Температурни напрежения

Свободно разширение:
```
ΔL = α · ΔT · L
```

Напълно задържано разширение:
```
σ = E · α · ΔT
```

Стомана, ΔT = 100 °C: σ = 210000 · 12e-6 · 100 = **252 MPa**. Затова температурата се подценява само веднъж.

α [1/°C]: стомана 12e-6; неръждаема 16–17e-6; алуминий 23e-6; месинг 20e-6.

## 10. Тръби под налягане

Тънкостенна (D/t > 20), вътрешно налягане p:
```
Тангенциално:  σ_t = p·D / (2t)
Надлъжно:      σ_a = p·D / (4t)
```

Дебелостенна (Ламе), вътрешна повърхнина:
```
σ_t = p·(r₀² + rᵢ²)/(r₀² − rᵢ²)
σ_r = −p
```

## 11. Еквивалентно напрежение (von Mises)

Това е числото, което Ansys показва по подразбиране и с което се сравнява границата на провлачване:

```
σ_e = √( ½·[ (σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)² ] )
```

При едноосен опън σ_e = σ. При чисто срязване σ_e = τ·√3.

```
Коефициент на сигурност = Rp0.2 / σ_e
```

von Mises е за пластични материали (стомана, алуминий). За крехки — чугун, керамика, закалени стомани — по-подходящо е максималното главно напрежение (`nodal_principal_stress`), защото те се късат на опън, а не се провлачват.

## 12. Мрежова сходимост

Един резултат не е резултат. Смята се два-три пъти с все по-фина мрежа:

| Размер на елемента | σ_max |
|---|---|
| 4 mm | 62 MPa |
| 2 mm | 78 MPa |
| 1 mm | 80 MPa |
| 0.5 mm | 81 MPa |

Тук стойността се успокоява около 80 MPa — това е отговорът. Ако вместо да се успокоява, продължи да расте без край (80 → 120 → 190 → 300), значи се гледа сингулярност, а не физика — виж `errors.md`.

Правилото: **сгъстяването се прави локално**, само в зоната, която се гледа. Глобалното сгъстяване изяжда бюджета от възли безсмислено.
